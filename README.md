# Lamis Saidi Portfolio

Modern Next.js portfolio for deployment on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Create a GitHub repository and upload this project.
2. Import the repository in Vercel.
3. Vercel detects Next.js automatically.
4. Deploy.

No environment variables are required.

## Personal links

The current portfolio includes:
- LinkedIn
- Email
- ESPRIT
- IPEIEM
- CV PDF

The exact certificate URLs were not present in the supplied CV PDF, so certificate cards are intentionally prepared for those links rather than inventing URLs.

## Customize

Edit `app/page.tsx` for text, URLs, projects and certificate links.
Edit `app/globals.css` for colors, spacing and visual style.
